# Portofoliu de programare

Proiectele mele de grafică, dezvoltare de jocuri, simulări, compilatoare și utilitare de zi cu zi. Deschide un proiect pentru a vedea ce face și cum îl poți folosi.

## Utilitare

Instrumente pe care le-am creat și le folosesc personal. Toate trei au fost realizate integral prin vibe coding.

| Proiect | Ce face |
| --- | --- |
| [Empire](utilitare/Empire) | Compilează și gestionează proiecte printr-un instrument modular în linie de comandă, scris în Python |
| [TExplorer](utilitare/TExplorer) | Gestionează fișiere în terminalul Linux, cu file, operații pe fișiere și o linie de comandă |
| [DockerTaskManager](utilitare/DockerTaskManager) | Monitorizează și controlează containere Docker și proiecte Compose dintr-un panou în terminal |

## Jocuri

## Motoare de jocuri și biblioteci

| Proiect | Ce face |
| --- | --- |
| [PrimordialPower](motoare-de-jocuri/PrimordialPower) | Un motor C# cu servicii de platformă, randare, inspecție și instrumente de dezvoltare |
| [QuantiX](motoare-de-jocuri/QuantiX) | Un motor C# cu un renderer OpenGL și demonstrații de jocuri FPS, cu voxeli și cu portaluri |
| [UnivKit](motoare-de-jocuri/UnivKit) | Oferă infrastructură C# pentru aplicații, ferestre, sunet și resurse |
| [OpenUL](motoare-de-jocuri/OpenUL) | Experimentează cu pachete reutilizabile pentru grafică, matematică, resurse și integrarea cu platforma |
| [PrimordialPowerCpp](motoare-de-jocuri/PrimordialPowerCpp) | Un motor experimental C++ cu OpenGL, o scenă 3D, o cameră mobilă și clase pentru geometrii, materiale și shadere |

Pentru QuantiX, am proiectat cadrul de randare, apoi am realizat integral prin vibe coding rendererul OpenGL și jocurile demonstrative construite pe el.
