# StarPixel

Un prototip de joc spațial cu vedere de sus, scris în Lua cu LÖVE. Pilotează o navă între sectoare, explorează fundaluri înstelate și deschide harta sectoarelor pentru a vedea unde te afli.

## Joacă

Necesită LÖVE. Din acest director:

```bash
love 0.1.2
```

Alege **New Game** din meniu.

| Tastă | Acțiune |
| --- | --- |
| W / A / S / D | Deplasează nava |
| M | Afișează sau ascunde harta |

Versiunea 0.1.2 este punctul de pornire recomandat. Versiunile anterioare sunt disponibile în [0.1.0](0.1.0) și [0.1.1](0.1.1).

Este un prototip: **Load Game** și **Settings** sunt opțiuni provizorii care închid aplicația. Titlul ferestrei versiunii 0.1.2 afișează încă 0.1.1.
